# Drag-Notes

A customizable, drag-and-drop note-taking application for organizing your thoughts and ideas.

## Features

- 📝 Create and manage notes with ease
- 🎨 Customize the look and feel of your notes
- drag-and-drop Drag notes around to organize your workspace
- 📥 Export your notes in multiple formats
- ☁️ Sync your notes across devices
- 📱 Available on web and mobile

## Tech Stack

### Frontend
- React
- TypeScript
- Sass
- Material UI

### Backend
- Node.js
- MongoDB
- Express.js

## Prerequisites
- Node.js version 14 or later
- MongoDB version 4.2 or later

## Installation

1. Clone the repository
```bash
git clone https://github.com/CodeMaker46/Drag-Notes.git
cd Drag-Notes
```

2. Install the dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

## Usage
Open your browser and navigate to `http://localhost:3000` to start using the application.
